# Buxa Framework 0.15.12

- Moved custom NPC Drop quantity weights below Drop destination.
- Added a saved, optional custom-weights switch. Disabled is the default for new entries; existing legacy weights remain enabled.
- When disabled, all quantities in the selected range have equal odds. Custom weights are preserved for later re-enabling.
- Collapsed the custom-weights controls until requested, avoiding lengthy forms.
- Fixed the NPC Drop Rules dialog height and added internal scrolling so changing the range cannot resize the popup.
