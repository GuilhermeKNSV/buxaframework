# Buxa Framework v0.13.40 — Recursive Image Library

- Folder gallery includes images directly in the chosen folder and in ALL nested folders recursively (no search text needed).
- Picking a child folder scopes gallery/search/used/favorites to that subtree.
- New Default folder button beside User data and Core data returns to Module Configuration → Addons → Icon Source.
- Every new artwork picker continues to start at that configured source and folder, regardless of the selected image or caller-provided target.
- Asynchronous cancellable directory scan, cached FilePicker results, scrolling gallery pagination and folder/image scan progress.
- No legacy code, file moving/creating/uploading, or background removal.
