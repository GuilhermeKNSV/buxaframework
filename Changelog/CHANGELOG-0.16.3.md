# Buxa Framework 0.16.3

- Item rarities: configurable beam opacity (0-100%) for each default/custom rarity, separate from item card opacity.
- GM Controls > Item > Trashcan: drag Scene Items, Actor inventory items or world Item documents into the delete slot, with confirmation.
- GM Select mode: click physical scene items to select, then delete selected with one confirmation. GM-authoritative, serialized, non-replayable scene deletion.
