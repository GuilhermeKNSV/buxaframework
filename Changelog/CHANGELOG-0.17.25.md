# Buxa Framework v0.17.25 — Module Configuration visual refinement

Presentation-only update for **all Module Configuration sections and subtabs**.

- Applied a unified navy/glass-like material vocabulary, a readable typography scale, subtle shadows and Buxa’s existing sharp-corner identity.
- Improved navigation hierarchy, active tab states, scrollable layouts and consistent section/card spacing.
- Aligned the Player Sheet fields, resources, attributes, proficiencies, stats, rebirth rules and item rarity editors.
- Improved Inventory spacing, checkbox separation, equipment layout, NPC settings, UI warning position cards and addon statuses.
- Reskinned the original native selects, checkbox toggles, radio controls, range fills, color swatches, icon picker buttons and list actions without replacing their form controls.
- Enhanced contextual hover/focus/active states, entrance/expand transitions, responsive layouts, and reduced-motion behavior.
- Added a visual **unsaved changes** cue to the Save/Reset footer; reset clears this indication after committing defaults.
- Added focused presentation regression tests.

**No settings schema, save/submit behavior, stored world/player data, tab names, settings options, or game mechanics were modified.**
