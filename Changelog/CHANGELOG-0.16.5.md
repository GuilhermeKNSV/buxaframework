# Buxa Framework 0.16.5 — World Directory Tabs

- Bottom Main/+ tabs for Items, Actors, and Scenes, persisted as real Foundry world folders.
- Click + to create a tab. Move world entries or entire folders by dropping them on tabs.
- Each tab shows its own content, including nested folders; Main remains the default/shared destination.
- Right click a custom tab to Rename, Delete tab (move contents to Main), or Delete all (delete contents recursively after a warning).
- Prevent moving Main/tab roots and cross-type documents; preserve nested folder relationships.
- GMs manage tabs; players can browse them without edit controls.
- Added focused regression tests for all three document types.
